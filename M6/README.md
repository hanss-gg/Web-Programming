## 1. JavaScript dan Fungsinya ##

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif dan dinamis. Kegunaannya antara lain untuk membuat animasi, memvalidasi formulir, dan merespons tindakan pengguna pada website.

## 2. jQuery dan Fungsinya ##

jQuery adalah library JavaScript yang mempermudah penulisan kode JavaScript. Kegunaannya antara lain untuk memanipulasi HTML dan CSS, menangani event, membuat animasi, serta melakukan komunikasi dengan server menggunakan AJAX.

## 3. Perbedaan JavaScript dan jQuery ##

1. JavaScript adalah bahasa pemrograman, sedangkan jQuery adalah library yang dibuat menggunakan JavaScript.

2. JavaScript dapat digunakan tanpa library tambahan, sedangkan jQuery membutuhkan library jQuery agar dapat digunakan.

3. JavaScript membutuhkan kode lebih panjang untuk tugas tertentu, sedangkan jQuery menyediakan sintaks yang lebih singkat dan praktis.

4. JavaScript dapat digunakan untuk berbagai kebutuhan pemrograman web, sedangkan jQuery berfokus pada mempermudah manipulasi HTML, CSS, dan animasi.

5. JavaScript merupakan dasar dari jQuery, sehingga jQuery tidak dapat digunakan tanpa JavaScript.
